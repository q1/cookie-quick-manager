# Cookie Loom 0.1.2 preview 1

Large backup previews now keep the interface responsive. Selected files are
read in a disposable worker, and their contents no longer fill the textarea.
Large pasted imports also use a worker; small pastes keep the fast inline path.
Canceling or closing releases the worker and prevents stale preview results.
Store/collision summaries avoid repeated work. Browser cookie write safeguards
and explicit import confirmation remain unchanged.

The Rust/Wasm investigation is committed as an optional reproducible lab. It
passed 1,022 differential cases per browser, but did not demonstrate a consistent
end-to-end advantage and adds payload/memory. Rust is excluded from the shipped
extension and normal build requirements. See [the measurements and tradeoffs](https://github.com/q1/cookie-quick-manager/blob/fpi/docs/rust-experiment.md).

Browser ZIPs are about 89 KB, roughly 6% larger than 0.1.1 to support the worker;
popup/workbench startup JavaScript is unchanged. Large-file selection and frame
blocking improve; worker startup and result cloning can increase review latency.

Validation: 159 unit tests, 64 browser workflows, four compiled Chrome workflows
on Chrome 132, and 14 native Firefox checks on Firefox 140/151, including loading
the production preview worker under extension CSP. Both browser builds satisfy
existing size budgets, and their source archive rebuilds every file byte for byte.

Desktop targets remain Chromium 132+ and Firefox 140+. Packages are **unsigned**:
Chrome uses developer-mode Load unpacked; Firefox uses a temporary installation
through `about:debugging`, removed after restart. Use a fresh browser profile.
Store submissions are prepared; signing/publisher access and manual permission,
private-window, and installation/update checks remain separate release work.

Cookie Loom remains a local, GPL-licensed rewrite inspired by Cookie Quick
Manager, without telemetry, accounts, cloud sync, or uploads. Exports may contain
credentials. Previous preview tags and assets are unchanged.
