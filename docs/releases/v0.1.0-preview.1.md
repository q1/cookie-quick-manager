# Cookie Loom 0.1.0 preview 1

The first public preview of Cookie Loom: a new local-first cookie manager for
desktop Chromium and Firefox, independently rewritten from Cookie Quick Manager.

## What's included

- Quick controls for the current site and a searchable cookie workbench.
- Create, edit, protect, and remove cookies with full store/path/partition identity.
- Explicit cleanup confirmation, stale-edit guards, and short-lived undo.
- JSON and Netscape import/export, legacy migration, and developer value tools.
- Light/dark themes, responsive layouts, and keyboard shortcuts.
- No accounts, telemetry, backend, or remote runtime code.
- A pinned Bun 1.4.3 build toolchain with native typechecking and parallel unit
  tests, plus reproducible source and release metadata.

The browser extension version is `0.1.0`. This GitHub tag is a preview identifier;
it does not imply browser-store approval or signing.

## Install the preview

Download the matching ZIP and `SHA256SUMS`. On Linux/macOS, verify the downloaded
files with `sha256sum --check SHA256SUMS` (or `shasum -a 256 --check SHA256SUMS`).
Download all listed files for a complete checksum check.

**Chromium 132+:** extract `cookie-loom-0.1.0-chrome.zip` into a folder, open
`chrome://extensions`, enable Developer mode, choose Load unpacked, and select
that folder. Keep the folder for as long as the extension is installed.

**Firefox 140+:** extract `cookie-loom-0.1.0-firefox.zip`, open
`about:debugging#/runtime/this-firefox`, choose Load Temporary Add-on, and select
the extracted `manifest.json`. This installation disappears when Firefox closes.
Persistent installation requires a Mozilla-signed build; none is included here.

Invoke Cookie Loom and choose **Allow website access**. This grants access to all
HTTP/HTTPS websites. Use a disposable profile and synthetic cookies when trying
the preview. Read [the privacy policy](https://github.com/q1/cookie-quick-manager/blob/fpi/PRIVACY.md).

## Verification and limitations

The source ZIP rebuilds all 22 files in each browser build byte for byte, and each
browser ZIP is compared with those verified build files. `RELEASE.json` records
the exact source commit, build run, tool version, and archive hashes.

Native cookie checks cover Firefox 140 and 151; compiled Chromium checks cover
Chrome 132 and Chromium 149. The suite also includes 146 unit tests and 57
Playwright tests. See [the verification record](https://github.com/q1/cookie-quick-manager/blob/fpi/docs/verification.md)
for details and test-only manifest changes.

Native permission dialogs, signed/store installation, upgrades, and real private
window UI still require manual verification. Mobile and Safari are not supported
release targets. All packages are unsigned. Cookie protection applies only to
Cookie Loom cleanup; exports can contain login credentials; undo is temporary.

## Source and feedback

`cookie-loom-0.1.0-sources.zip` includes `bun.lock`, `bunfig.toml`, `.bun-version`,
the pinned tooling patch, shared core, build scripts, GPL license, and attribution.
With Bun 1.4.3, extract it and run `bun install --frozen-lockfile --ignore-scripts`
followed by `bun run build` to reproduce the extension.
