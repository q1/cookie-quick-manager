# Cookie Loom 0.1.1 preview 1

Cookie Loom's second GitHub preview makes the cookie workbench smaller and more
responsive, especially on large profiles. Download the Chrome or Firefox ZIP,
corresponding build-input source, release metadata, and SHA-256 checksums below.

- The smaller Preact renderer cuts browser packages from about 138 KB to 84 KB.
  Editor, import/export, copy tools, and settings load locally when opened.
- The current-site popup reads its captured tab's cookie scope; it keeps parent
  paths, containers, first-party isolation, and supported partitions intact.
  Edits validate their matching records without scanning the whole profile.
- Large domain lists show 50 entries initially, with complete search and Show
  more. Narrow layouts keep the domain filter across resizing. Refresh shows
  progress; dirty drafts and nested-dialog keyboard focus remain protected.
- Native benchmarks, raw samples, and CI size budgets make future regressions
  visible. See the [measured before/after comparison](https://github.com/q1/cookie-quick-manager/blob/fpi/docs/extension-performance.md)
  and [review record](https://github.com/q1/cookie-quick-manager/blob/fpi/docs/review-2026-10-12-optimization.md).

The release pipeline checks 153 Bun tests, 58 browser workflows, four compiled
Chrome workflows at the minimum Chrome 132 version, and 14 native Firefox checks
on Firefox 140 and 151. It validates both MV3 builds and rebuilds the source ZIP
in a fresh directory, comparing every packaged file byte for byte.

Targets: desktop Chromium 132+ and Firefox 140+. These packages are **unsigned**:
unzip Chrome's package and use developer-mode Load unpacked; Firefox's ZIP can
be temporarily loaded through `about:debugging` and is removed after restart.
Use a fresh browser profile for preview testing. Details are in the
[build and installation guide](https://github.com/q1/cookie-quick-manager/blob/fpi/README.md#build-the-extension).

Mozilla Add-ons and Chrome Web Store submissions remain prepared, awaiting
publisher access. Native permission prompts, signed installation/upgrade paths,
and real private-window UI still require manual verification. Mobile and Safari
are not supported targets. The all-website optional grant remains required.

Cookie Loom is an independent GPL-licensed rewrite inspired by Cookie Quick
Manager. It runs locally, without telemetry, accounts, cloud sync, or uploads.
Exports may contain usable credentials. Protection applies to Cookie Loom's
cleanup, not site/browser deletion. Source, attribution, and licenses remain
available; the previous preview's tag and assets are unchanged.
