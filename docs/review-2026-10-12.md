# Bun migration and preview release review

Reviewed on 2026-10-12 against the merged rewrite (`6c72b53`). The scope includes
the maintained Bun 1.4.3 toolchain, package/source verification, release workflow,
minimum-browser CI, and browser-store preparation. Historical sources remain
archived and excluded from the active build.

## Findings and corrections

Native Firefox testing reproduced a development-tool incompatibility: web-ext
10.7.0 forwarded a startup socket refusal through Node's deprecated `domain`
module, causing an unhandled error under Bun before Firefox's debugger was ready.
The pinned patch replaces that startup error forwarding with an explicit listener,
rejecting the original `ECONNREFUSED` before disconnecting so web-ext's existing
retry logic still works. The listener is removed on successful root handshake.
Two socket-level regressions check refusal and a successful handshake followed by
another RDP request. The patch is supplied in source archives and is not bundled
into the extension.

An independent agent reviewed the completed implementation read-only and found
no P0–P2 defects. Its P3 observation was that the build verifier still rejected
Vitest tooling but omitted the new Bun test/runtime imports. The verifier now
rejects `bun:` imports and `Bun.*` globals in production code. Current builds pass.

The review checked tag/version validation, an annotated tag pointing to a merged
commit, same-run artifact selection, source revision checks, checksum validation,
and read-only verification jobs. Only the publication job receives contents-write
permission. Existing releases are not overwritten. Stable/store promotion remains
separate from the automated unsigned preview path.

## Validation

- All original 144 cookie tests retained; 146 Bun unit tests pass across five files.
- All 57 Playwright tests pass under Bun, including the responsive viewport matrix.
- The three compiled-extension workflows pass on official Chrome 132.0.6834.159.
- All 13 native checks pass on Firefox 140.0 and Firefox 151.0 under Bun.
- Native Bun type checks pass for extension, core, and tooling projects. The
  retained TypeScript compiler also passed the extension/core projects.
- Version guard, frozen install, production audit, formatting, both builds,
  Firefox validation, and actionlint pass.
- Extracted source installs with a frozen Bun lockfile and scripts disabled,
  then reproduces all 22 files in each browser build. Both ZIP inventories and
  contents match those builds byte for byte.
- A deliberately modified browser ZIP is rejected by the source verifier.
- Seven tag-policy fixtures exercise valid promotion and rejection of missing,
  mismatched, stable, lightweight, undocumented, and unmerged tags.
- A disposable Linux process hierarchy confirms `run.noOrphans` cleanup after
  abrupt supervisor exit.

The [performance record](toolchain-performance.md) reports warm local timing
samples and their limits. The [verification checklist](verification.md) retains
manual permission, signed installation/update, and private-window checks.
One existing development-only node-forge advisory is documented in
[dependency review](dependency-review.md); the production audit is clean.

This record covers development verification and code review. It does not claim
browser-store approval, signing, or mobile certification.
